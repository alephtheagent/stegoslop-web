🧠 Steganography Forensic Insights

In natural uncompressed photographs, Bit 0 (LSB) looks like random thermal/sensor Gaussian noise. When encrypted data (AES-256-GCM) is embedded, the bits exhibit maximum entropy (pseudo-random uniform distribution). When unencrypted plaintext or patterned data is embedded, distinct structured stripes or sharp transitions become vividly visible in the X-Ray inspector! Higher bit planes (Bits 5, 6, 7) represent visual contours and luminance edges of the carrier image.

🛡️ 100% Client-Side Privacy Guarantee

Zero data transmission. No tracking. Pure local cryptography.

StegoSlop is engineered as a 100% client-side application. All steganographic embedding, bit slicing, decryption, and media synthesis happen entirely within your local browser's memory sandbox via WebAssembly compiled from Rust.

🔒 Zero Network Uploads

Open your browser's Developer Tools (Network Tab): not a single byte of your photos, audio, passwords, or secret messages is transmitted to any server. You can even run this application completely offline without an internet connection.

⚡ Rust + WebAssembly

Powered by a high-performance Rust core compiled to WASM. Memory is managed safely without buffer overflows, with direct SIMD/typed-array access for real-time 60fps bitplane rendering and sub-millisecond audio LSB processing.

📐 StegoSlop Binary Protocol Specification (v1)

Cross-compatible steganography protocol architecture across Android, Desktop, and Web.

+-------------------+----------------+---------------+-------------------+ | Field | Offset (Bytes) | Size (Bytes) | Description | +-------------------+----------------+---------------+-------------------+ | MAGIC_BYTES | 0..3 | 4 | "SLOP" (0x534C4F50)| | PAYLOAD_TYPE | 4 | 1 | 0x01:Text, 0x02:Img| | | | | 0x03:Aud, 0x04:File| | FLAGS | 5 | 1 | Bit 0: Encrypted | | | | | Bit 1-2: BPU code | | | | | Bit 3: HasFilename| | PAYLOAD_LEN | 6..9 | 4 | Big-Endian uint32 | | CRC32_CHECKSUM | 10..13 | 4 | Big-Endian uint32 | | [SALT] (optional) | 14..29 | 16 | PBKDF2 Salt | | [IV] (optional) | 30..41 | 12 | AES-GCM Nonce/IV | | [FILENAME] (opt) | variable | 1 + N (<=255) | Length + UTF-8 | | PAYLOAD_DATA | variable | N | Secret Ciphertext | +-------------------+----------------+---------------+-------------------+
  • Cryptographic Standard: AES-256-GCM authenticated cipher with 128-bit authentication tag, derived from password via PBKDF2-HMAC-SHA256 with 100,000 iterations.
  • Integrity: Hardware-accelerated CRC-32 checksum calculated over ciphertext guarantees detection of bit-rot, compression artifacts, or tampering.
  • Carrier LSB Sequential Injection: Data is sequentially distributed across R, G, B channels (Alpha channel preserved 100% intact to prevent rendering glitches). Audio uses 16-bit PCM little-endian samples.
